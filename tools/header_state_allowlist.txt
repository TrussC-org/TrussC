# Header-inline state accepted by tools/check_header_state.py (CI).
#
# Each entry is a function-local static or an inline variable in core/include
# that a hot reload guest can get its own copy of (docs/ARCHITECTURE.md, "One
# instance per process"). On WINDOWS it always does: the guest is a DLL, and a
# DLL compiles every header-inline function and variable into itself. Linux
# and macOS give the guest the host's copy only when the host contains the
# definition too, that is, when host code uses it. State that only guest code
# touches is the guest's own there as well (on Linux, a fresh copy for every
# reloaded generation). A per-module copy of every entry below breaks nothing,
# on any platform.
#
# Format:  <header> <scope>::<name>   # <category>: <reason>
#          <header> <scope>::*        # immutable: <reason>   (every immutable
#                                       finding in that scope: a constants table)
#
# The category must be one of these four (the checker rejects anything else):
#
#   harmless       a per-module copy breaks nothing: a cache of derived data,
#                  a counter only one side uses. NOT a cache of GPU objects
#                  that nothing frees (sokol_gl contexts, shaders,
#                  pipelines, samplers, font atlases): every reloaded
#                  generation would build and keep a new set in the host's
#                  sokol pools, and sokol_gl has 4 context slots, sokol_gfx
#                  32 shader slots.
#   immutable      const data, the same in every copy
#   host-only      only code compiled into the host touches it (the core loop
#                  in TrussC.h, which the host's main.cpp instantiates, and the
#                  .cpp files of TrussC.lib); a guest's copy is never used
#   no-hot-reload  only on a path hot reload never takes (Android, headless)
#
# The declaration in the header carries a comment saying the same, so whoever
# edits it sees why the per-module copy is fine.
#
# A warn-once flag is a function-local `static OnceGate` (tc/utils/tcOnceGate.h)
# instead. The checker accepts it by its type, so it needs no entry here.
#
# State that must be one per process (a singleton, a registry, a setting app
# code writes and the core loop reads) does not belong here: define it
# non-inline in a .cpp (tcGlobal.cpp or a sibling) and declare an accessor in
# the header.
